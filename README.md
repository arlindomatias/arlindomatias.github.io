# arlindomatias.github.io

Personal academic website of Arlindo César Matias Pereira Filho, published with GitHub Pages at https://arlindomatias.github.io.

## Structure

- `index.html`: the whole site (HTML, CSS and a small script for the hero volcano plot). No build step.

## Editing

Edit `index.html` and push to `main`. GitHub Pages republishes the site in about a minute.

Items still to fill in are marked with `TODO` comments (degree years, email, ORCID, Lattes and Google Scholar links).
